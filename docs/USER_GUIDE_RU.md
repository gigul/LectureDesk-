# Как пользоваться LectureDesk

Инструкция для версии 0.1.0, подготовлена 12 октября 2026 года. Названия кнопок приведены для русского интерфейса. Сборки: Mac с Apple Silicon (arm64) и Mac с процессором Intel (x64) на macOS 15 или новее, а также Windows 10/11 x64 (процессоры Intel и AMD). Сборка для Intel Mac пока не проверена на реальном Intel-компьютере.

Обычный сценарий: выбрать предмет → записать лекцию → дождаться расшифровки → создать конспект или перевод → задать вопросы в чате → экспортировать результат и сделать резервную копию.

**1. Установите и откройте приложение.**

На Mac откройте `LectureDesk-0.1.0-mac-arm64.dmg` (Apple Silicon) или `LectureDesk-0.1.0-mac-x64.dmg` (Intel), перенесите LectureDesk в папку «Программы» и запустите его оттуда. На Windows запустите `LectureDesk-0.1.0-windows-x64-setup.exe` и пройдите шаги установщика; сборка не подписана, поэтому SmartScreen может показать предупреждение («Подробнее» → «Выполнить в любом случае»). Node.js и Python для работы установленного приложения не нужны.

Текущая сборка не подписана и не нотариально заверена Apple. Если macOS блокирует запуск и вы доверяете этой сборке, после попытки открытия перейдите в «Системные настройки → Конфиденциальность и безопасность» и подтвердите открытие конкретного приложения. Название кнопки зависит от версии macOS; на снимке Apple она называется «Все равно открыть». Затем подтвердите запуск кнопкой «Открыть». Подробности — в [инструкции Apple](https://support.apple.com/ru-ru/102445).

**2. Пройдите первоначальную настройку.**

Мастер состоит из пяти шагов. На шаге «Ваши языки» выберите язык интерфейса, язык лекций и язык результата. Например: русский интерфейс, польские лекции, результат на русском. Транскрипт содержит только язык лекций и английский (термины, цитаты). Фрагменты на других языках не попадают в текст: приложение один раз повторяет распознавание со строгой подсказкой языка, а если результат снова неверный, показывает на месте фрагмента предупреждение. Аудио при этом сохраняется. Автоматического определения языка больше нет: если в прежней версии было выбрано «Определять автоматически», перед следующей записью или импортом приложение один раз попросит выбрать язык лекций.

На шаге «Подключите AI» можно указать свой ключ OpenAI API или просто нажать «Продолжить». Без ключа доступны запись, прослушивание, организация библиотеки, импорт документов и локальное распознавание текста на изображениях. Для расшифровки речи, перевода, конспектов и чата нужен API.

Ключ создаётся в [кабинете OpenAI](https://platform.openai.com/api-keys), как описано в [официальной документации OpenAI](https://developers.openai.com/api/docs/quickstart). Вставьте его в поле «Ключ OpenAI API» и нажмите «Проверить и сохранить ключ». Позже это можно сделать в «Настройки → API и модели». Ключ хранится с защитой операционной системы и исключается из резервных копий и пакетов лекций.

В разделе «Приоритет качества» доступны «Сбалансированный» и «Максимальное качество». В «Модели AI» можно отдельно выбрать модели распознавания, перевода, конспектов и чата. «Проверить доступные модели» проверяет их видимость для вашего ключа; отдельная операция всё ещё может завершиться ошибкой доступа или лимита API.

На шаге «Проверьте звук» выберите источник и нажмите «Проверить звук». Для микрофона произнесите несколько слов; для системного звука включите аудио на компьютере. Индикатор уровня должен реагировать. Затем нажмите «Остановить проверку». Этот тест не создаёт лекцию.

На шаге «Храните локально» можно оставить стандартную папку библиотеки. Для резервных копий при желании выберите папку iCloud Drive или Google Drive, уже синхронизируемую установленным клиентом. На последнем шаге создайте первый предмет либо оставьте поле пустым и нажмите «Открыть библиотеку».

**3. Подготовьте предмет и источник звука.**

Слева нажмите «Новый предмет», укажите название и при желании цвет и «Словарь предмета». В словарь удобно добавить фамилии преподавателей, сложные термины и сокращения: это подсказки для распознавания речи.

Откройте «Настройки → Аудио и обработка». Выберите «Микрофон», если записываете преподавателя в аудитории; «Звук компьютера», если записываете онлайн-лекцию или воспроизводимое аудио; «Микрофон + компьютер», если нужны оба источника. Для микрофона можно выбрать устройство.

Разрешите LectureDesk доступ к микрофону и, для системного звука, запись экрана и системного звука в настройках macOS. Приложение сохраняет аудио; видео экрана не сохраняется. При совместном захвате используйте наушники, чтобы звук из динамиков не попадал в запись повторно через микрофон.

Если нужен текст во время лекции, оставьте включённым «Распознавание в реальном времени». По умолчанию оно включено. Звук передаётся в OpenAI непрерывным потоком, без нарезки на 10-секундные куски. Модель по умолчанию `gpt-4o-transcribe` сама определяет на сервере, где заканчивается фраза. Модели `gpt-live-transcribe` и `gpt-transcribe` такого не умеют: для них LectureDesk завершает фразу на паузах, которые находит сам. Под выбором модели в «Настройки → AI → Модели AI» показано, какой режим использует выбранная модель. Если распознавание во время записи выключено, запись расшифровывается из сохранённого аудио после её завершения. Сохраните настройки до начала записи. В этой версии изменение полных настроек во время активной записи ограничено; быстрые переключатели перевода и конспекта на панели записи доступны отдельно.

**4. Запишите лекцию.**

Выберите нужный предмет слева и нажмите «Записать лекцию». Приложение создаст новую лекцию. Если предмет не выбран, запись окажется в «Без предмета».

Во время записи следите за таймером и индикатором звука. «Пауза» приостанавливает запись, «Продолжить» возобновляет её, «Завершить» заканчивает и сохраняет запись. Пауза отмечается в истории как перерыв.

Аудио сохраняется на диск по ходу записи (10-секундные файлы служат только резервной копией и для прослушивания). Если интернет пропадёт, локальная запись продолжится. Часть записи, которую сервер не успел расшифровать, будет расшифрована из сохранённого аудио: приложение разрезает её только по паузам и не отправляет тишину. Это происходит после восстановления соединения при доступном ключе. Пока идёт запись, не закрывайте крышку ноутбука и не переводите компьютер в сон вручную.

После завершения откройте лекцию. В меню «… → Изменить» можно изменить название, тему, дату, теги и предмет. Строка поиска ищет по названиям, тексту и материалам; рядом доступны сортировка и фильтр тегов.

**5. Прочитайте расшифровку и прослушайте запись.**

Откройте вкладку «Транскрипт». При включённом распознавании и доступном API текст появляется по мере обработки. Предварительный текст может ещё изменяться. После остановки дождитесь завершения оставшихся задач в панели «Фоновые задачи» внизу окна.

Встроенный плеер позволяет слушать запись, перематывать и менять скорость. Метка времени отмечает начало каждой фразы; нажатие на неё запускает воспроизведение с этого места. Это не точное время каждого слова.

Если запись была сделана без ключа API, она расшифруется из сохранённого аудио автоматически, как только ключ будет подключён. Чтобы заново распознать уже готовую лекцию другой моделью, откройте меню «… → Улучшить транскрипт» и нажмите «Распознать заново». Эта операция отправит сохранённое аудио в API; результат появится отдельной версией.

**6. Создавайте версии, переводы и конспекты.**

«Изменить» позволяет исправить текст и сохранить новую версию. Исходная расшифровка сохраняется отдельно. Во вкладке «Версии» можно выбрать результат, «Сделать активной» и «Сравнить версии».

«Быстрые действия» открывают обработку текста. Сначала укажите область в «Применить к»: «Всей лекции», «Выбранной версии» или «Выделенному тексту». Затем выберите, например, «Краткое содержание», «Подробный конспект», «Объяснить проще», «Термины», «Задания и сроки», «Вопросы к экзамену» или «Карточки для повторения». Чтобы обработать выделение, сначала выделите текст в лекции. Результат сохраняется отдельно от исходника.

Для готовой лекции откройте «Перевод», выберите язык и нажмите «Перевести всю лекцию». Конспекты доступны во вкладке «Конспект»; кнопка «Обновить конспект» запускает обработку вручную.

Для автоматической обработки заранее включите в «Настройки → Аудио и обработка» «Перевод во время записи» и/или «Конспект во время записи». Порог перевода по умолчанию — 50 новых слов, анализа — 500. «Финальный конспект после записи» включает создание итогового конспекта без повторного распознавания аудио. Язык результата выбирается в «Настройки → Общие».

«Улучшить транскрипт» заново распознаёт именно аудио и является дополнительной операцией API. «Переформулировать» изменяет уже имеющийся текст. В текущей версии это разные действия.

**7. Добавляйте учебные материалы.**

Нажмите «Импорт файлов» или перетащите файлы в библиотеку. Поддерживаются аудио, PDF, DOCX, PPTX, TXT, Markdown и изображения. Чтобы приложить документы к конкретной лекции, сначала откройте её; материалы предмета можно добавить через меню предмета.

Вкладка «Файлы» показывает приложения. «Извлечённый текст» открывает распознанное содержимое, «Открыть оригинал» — исходный файл. Для PDF и презентаций сохраняются номера страниц или слайдов. Сканированные документы и изображения обрабатываются локальным OCR и отмечаются соответствующей меткой.

Импорт аудио может создать отдельную лекцию, если выбранная лекция уже содержит запись: существующее аудио сохраняется. При ошибке обработки файла доступна кнопка «Повторить». Проверяйте текст OCR, особенно формулы, таблицы и рукописные заметки.

**8. Задавайте вопросы в чате.**

Нажмите значок сообщения справа сверху. В «Выбранный контекст» укажите одну лекцию, несколько лекций, предмет или всю библиотеку; при необходимости отметьте «Дополнительные файлы».

Выберите «Режим ответа». «Только материалы» ограничивает ответ выбранными источниками. «Материалы + общие знания» разрешает дополнительные объяснения модели. Для «Материалы + поиск в интернете» также включите отдельную галочку «Разрешить поиск в интернете в этой беседе».

Примеры вопросов: «Объясни второй закон термодинамики простыми словами», «Какие задания упоминались на этой лекции?», «Сравни определения из двух лекций», «Составь вопросы для повторения всего предмета».

Enter отправляет вопрос, Shift+Enter добавляет новую строку. Проверяйте блок «Источники» рядом с ответом. «Новая беседа» начинает отдельный разговор; «История бесед» открывает сохранённые разговоры. Кнопка «Продолжить в чате» у версии делает её активной и открывает новый чат по этой лекции.

**9. Добавляйте свои действия.**

Откройте «Настройки → Свои действия → Создать действие». Укажите название, значок, инструкции, язык и формат результата. Модель можно выбрать отдельно или использовать модель для конспектов. «Закрепить в быстрых действиях» добавляет действие в основное меню обработки.

Пример инструкции: «Составь 10 вопросов для самопроверки по этому тексту. После каждого вопроса дай короткий ответ. Не добавляй факты, которых нет в материале». Сохраните действие, затем применяйте его через «Быстрые действия».

**10. Экспортируйте лекцию.**

Завершите запись и дождитесь нужного результата. Нажмите значок скачивания рядом с названием лекции. Выберите PDF, DOCX, Markdown или TXT, затем «Версия для экспорта» и «Экспорт». Укажите, куда сохранить файл.

«Оригинальное аудио» экспортирует запись. «Полный пакет лекции» создаёт файл `.lecturedesk` с материалами, версиями и метаданными. Другой пользователь LectureDesk может добавить пакет через «Импорт файлов». Ключ API в пакет не включается.

**11. Делайте резервные копии и восстанавливайте данные.**

В «Настройки → Хранение и копии» выберите существующую «Папку резервных копий». «Включать оригинальное аудио» добавляет записи; без него восстановленная копия не содержит исключённого аудио.

Для автоматических копий задайте интервал в часах и число последних копий, которые нужно сохранять. Интервал `0` отключает автоматические копии. Они создаются, пока приложение открыто, и откладываются на время активной записи. Для ручной копии завершите запись и нажмите «Создать копию».

В «История копий» выберите «Предпросмотр», проверьте состав и нажмите «Восстановить копию». Сначала остановите запись и завершите либо отмените ожидающие задачи. Восстановление добавляет данные к существующей библиотеке; повторное восстановление может создать дополнительные копии лекций.

Папка iCloud Drive или Google Drive используется для резервных архивов, а не для одновременного редактирования одной библиотеки на нескольких компьютерах. Перед восстановлением облачного архива дождитесь его полной загрузки на компьютер.

**12. Если возникла проблема.**

| Ситуация | Что сделать |
| --- | --- |
| Индикатор звука не реагирует | Проверьте источник, выбранный микрофон, разрешения macOS и наличие воспроизводимого звука. Повторите тест перед записью. |
| Аудио есть, текста нет | Проверьте ключ, интернет и «Фоновые задачи». Расшифровка из сохранённого аудио продолжится автоматически после подключения ключа. |
| Вместо текста предупреждение о языке | Фрагмент был распознан не на языке лекции и не на английском. Проверьте язык лекций в «Настройки → Общие». Распознанный текст можно раскрыть под предупреждением; аудио сохранено, а «Улучшить транскрипт» распознаёт запись заново. |
| «Лимит API исчерпан» или ошибка модели | Проверьте состояние API-аккаунта и доступ к модели. После устранения причины нажмите «Повторить» у задачи. |
| Приложение закрылось во время записи | Откройте его снова и нажмите «Восстановить запись» в уведомлении о прерванной записи. Сохранённые фрагменты остаются на диске; отсутствующее аудио приложение не восстанавливает из ничего. |
| Закончилось место | Освободите место, затем восстановите сохранённую запись. |
| Файл не обработался | Проверьте, открывается ли оригинал, и нажмите «Повторить» во вкладке «Файлы». |
| Резервная копия не открывается | Проверьте доступность папки и полную загрузку архива из облака; повреждённые архивы не принимаются. |
| Лекция удалена | Откройте «Корзина», выберите лекцию и нажмите «Восстановить». При удалении предмета его лекции остаются в «Без предмета». |

**Сочетания клавиш.**

| Действие | macOS | Windows после выпуска сборки |
| --- | --- | --- |
| Новая запись | ⌘R | Ctrl+R |
| Поиск | ⌘K | Ctrl+K |
| Открыть или закрыть чат | ⌘Shift+C | Ctrl+Shift+C |
| Настройки | ⌘, | Ctrl+, |
| Закрыть диалог | Esc | Esc |

Аудио и библиотека хранятся локально. AI-операции отправляют выбранное аудио или текст в OpenAI и могут быть платными. OCR работает локально. Реальные платные запросы API и Windows-сборка ещё не проверены; подробности текущих ограничений приведены в [отчёте проверки](VALIDATION.md).
