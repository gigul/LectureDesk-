# Internal integration contract

Shared DTOs and allowed IPC operations: `src/shared/types.ts`. Renderer calls `window.lecturedesk.call(method,args)`; fixed allowlist only. Main validates arguments and never returns API secrets. Renderer has no Node or filesystem access, apart from dropped File path through Electron webUtils.

Store agent owns `src/main/store.ts`, `src/main/materials.ts`, `src/main/portability.ts` and their tests. Export `Store` with `root`, `db` (node:sqlite DatabaseSync), `settings()`, `saveSettings(patch)`, `snapshot()` (returns subjects,lectures,tasks,recoverable,settings,actions only; root adds hasKey/platform/appVersion), `subjectSave({id?,name,color?,glossary?})`, `subjectDelete(id)` (orphan lectures), `lectureCreate({subjectId?,title?})`, `lectureGet(id)` returning LectureDetail, `lectureSave({id,...partial})`, `lectureTrash(id)`, `lectureRestore(id)`, `versionSave({lectureId,kind,title,content,model?,parameters?,sourceVersionId?})`, `versionActivate(lectureId,versionId)`, `segmentSave(Segment)`, `segmentUpdate(id,patch)`, `itemSave(item)` (idempotent by `(lectureId,sourceKey)`, returns the stored row), `itemUpdate(id,{text,status,error,language})`, `taskGet(id)`, `lecturePurge(id)`/`trashEmpty()` (also delete `transcript_items`), `gap(lectureId,at,reason)`, `taskAdd(kind,lectureId,payload,dedupeKey?)`, `taskUpdate(id,patch)`, `tasks()`, `materialSave(Material)`, `materialUpdate(id,patch)`, `actionSave(CustomAction)`, `actionDelete(id)`, `conversationCreate(context,mode,title?)`, `conversations()`, `messages(conversationId)`, `messageSave(ChatMessage)`, `usageSave(lectureId,operation,model,data)`, `close()`. Tables named subjects,lectures,segments,transcript_items,versions,materials,tasks,gaps,actions,conversations,messages,usage. `transcript_items` (schema v3): `id,lectureId,start,end` (lecture seconds), `text,status` ('done'|'rejected'), `source` ('live'|'file'), `model,language,error,sourceKey` (`live:<windowId>:<item_id>` | `range:<taskId>:<chunk>` | `segment:<segmentId>`), `createdAt`, unique `(lectureId,sourceKey)`. `LectureDetail.items` is ordered by start. Segment status `audio` = recorded audio kept for backup/playback whose text lives in items. SQL columns camelCase. JSON fields serialize/deserialize. Atomic task dedupe and immutable originals.

Materials module: `MaterialService(store, emit)` exports async `importPaths(paths,{lectureId?,subjectId?})`, `retry(id)`. Audio imports are copied and split with bundled ffmpeg at silences, persisted segments and tasks kind `transcribe` payload `{segmentId}` (per-segment path with silence guard and language checks). Others extracted by page/slide, images OCR with bundled Tesseract resources. Emit import progress/changed.

Portability: `Portability(store)` async `exportLecture(lectureId,versionId,format,destination)` format txt/md/docx/pdf/audio/package; `importPackage(path)`; `backup(folder,includeAudio,retention)`; `listBackups(folder)`; `preview(path)`; `restore(path)` merge with remapped IDs, never destructive replacement; coherent SQLite snapshots outside sync folder; ZIP archives and sha256 manifest, path validation, keys excluded. Archive data schema 2 adds `transcript_items`; schema-1 archives restore with no items. Restored `transcribe-range` tasks are never live; without audio they are cancelled.

AI agent owns `src/main/ai.ts`, optional provider/queue files and tests. Export `AIService(store,getKey,emit)`: `validateKey(key?)` returns `{valid,models:string[]}`; `models()`; `start()/stop()` background worker; `liveAppend(lectureId,pcm:Buffer,offsetBytes)` (continuous stream; windows, turn policy and disk gaps are internal); `livePause(lectureId)`; `liveStop(lectureId)`; `cancelLecture(lectureId):Promise<void>` (cancels queued/running work and live windows of a lecture, resolves once running requests stopped); `flush(lectureId)` scheduling translation leftovers/final notes; `runAction({lectureId,versionId?,text?,action,language?,customActionId?})` returns Task; `improve(lectureId)` returns Task; `chatSend({conversationId,message})` returns ChatMessage; `cancel(taskId)`, `retry(taskId)`. Durable transcribe, transcribe-range, translation, analysis and action tasks. `transcribe-range` payload `{windowId?,startByte,endByte|null,frontierByte,livePending,origin:'live'|'reconcile',model,liveModel?,language,glossary,gaps?,chunks?}` (bytes on the 48-bytes-per-ms lecture timeline). UI controls live settings and main updates settings. Live model policy: `turnPolicy(model)` = 'server' for gpt-4o(-mini)-transcribe (semantic_vad → server_vad → local), 'local' otherwise (turn_detection null, commits at locally detected pauses). Transcripts contain only the lecture language plus English; others are retried strictly and otherwise stored as rejected items. Final original version creation handled by AI when no transcription task or realtime window is outstanding (never overwrite once finalized); its content merges items and legacy segment text in time order, timestamps per speech turn. Work must persist first, API afterward. Chat retrieval scoped to selected IDs; complete coverage for summaries.

Root owns config, secure key, Electron main/preload, recording and renderer audio engine. Recording at 24kHz mono PCM via AudioWorklet, batches of ~250ms persisted to `.pcm.part` with fsync; 10s independent WAVs finalized atomically, stable seq and offsets. `RecordingHooks`: `append(lectureId,pcm,offsetBytes)` for every durable slice (contiguous across segments and pauses), `pause(lectureId)` after a pause tail is finalized, `end(lectureId)`; capture never queues transcription itself and saves new segments as `audio`. `record.start` `{lectureId,mode}` -> `{lectureId}`; `record.chunk` `{lectureId,pcm:ArrayBuffer,sequence:number}`; `record.pause/resume/stop` `{lectureId}`. Main alone holds secrets and sockets. `audio.url` `{lectureId,segmentId?}` -> URL and segment playlist metadata (renderer can simply use Segment paths through custom `lecture-audio://segment/id` URLs); `audio.sources` -> permissions/platform support. Mac target is 15+ with Electron 44 pinned to its documented ScreenCaptureKit path; Windows uses Electron's WASAPI loopback. No additional audio addon is required.

UI agent owns renderer except renderer/audio files. Root creates `src/renderer/audio/recorder.ts` exporting class `AudioCapture` with `devices():Promise<MediaDeviceInfo[]>`, `test(mode,deviceId,onLevel):Promise<()=>Promise<void>>`, `start(lectureId,mode,deviceId,onLevel,onError):Promise<void>`, `pause():Promise<void>`, `resume():Promise<void>`, `stop():Promise<void>`. Handles mixing/sampling/clipping/bounded buffering. UI calls record.start before capture start, capture.stop before record.stop, pause capture then record.pause, record.resume then capture.resume. Import picker args `{lectureId?,subjectId?}`; export `{lectureId,versionId?,format}` opens save dialog; folder.choose -> path|null; settings.save `{...settings patch}`; key.set `{key}`; key.validate `{key?}`; action.run args as AI above. Chat.create `{context,mode,title?}`, chat.send `{conversationId,message}`. Library event changed refreshes snapshot/detail. No demo data or fake successful operations. English/Russian/Ukrainian/Polish and themes. Stylish usable production app.
