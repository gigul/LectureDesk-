# Internal integration contract

Shared DTOs and allowed IPC operations: `src/shared/types.ts`. Renderer calls `window.lecturedesk.call(method,args)`; fixed allowlist only. Main validates arguments and never returns API secrets. Renderer has no Node or filesystem access, apart from dropped File path through Electron webUtils.

Store agent owns `src/main/store.ts`, `src/main/materials.ts`, `src/main/portability.ts` and their tests. Export `Store` with `root`, `db` (node:sqlite DatabaseSync), `settings()`, `saveSettings(patch)`, `snapshot()` (returns subjects,lectures,tasks,recoverable,settings,actions only; root adds hasKey/platform/appVersion), `subjectSave({id?,name,color?,glossary?})`, `subjectDelete(id)` (orphan lectures), `lectureCreate({subjectId?,title?})`, `lectureGet(id)` returning LectureDetail, `lectureSave({id,...partial})`, `lectureTrash(id)`, `lectureRestore(id)`, `versionSave({lectureId,kind,title,content,model?,parameters?,sourceVersionId?})`, `versionActivate(lectureId,versionId)`, `segmentSave(Segment)`, `segmentUpdate(id,patch)`, `gap(lectureId,at,reason)`, `taskAdd(kind,lectureId,payload,dedupeKey?)`, `taskUpdate(id,patch)`, `tasks()`, `materialSave(Material)`, `materialUpdate(id,patch)`, `actionSave(CustomAction)`, `actionDelete(id)`, `conversationCreate(context,mode,title?)`, `conversations()`, `messages(conversationId)`, `messageSave(ChatMessage)`, `usageSave(lectureId,operation,model,data)`, `close()`. Tables named subjects,lectures,segments,versions,materials,tasks,gaps,actions,conversations,messages,usage. SQL columns camelCase. JSON fields serialize/deserialize. Atomic task dedupe and immutable originals.

Materials module: `MaterialService(store, emit)` exports async `importPaths(paths,{lectureId?,subjectId?})`, `retry(id)`. Audio imports are copied and split with bundled ffmpeg, persisted segments and tasks kind `transcribe` payload `{segmentId}`. Others extracted by page/slide, images OCR with bundled Tesseract resources. Emit import progress/changed.

Portability: `Portability(store)` async `exportLecture(lectureId,versionId,format,destination)` format txt/md/docx/pdf/audio/package; `importPackage(path)`; `backup(folder,includeAudio,retention)`; `listBackups(folder)`; `preview(path)`; `restore(path)` merge with remapped IDs, never destructive replacement; coherent SQLite snapshots outside sync folder; ZIP archives and sha256 manifest, path validation, keys excluded.

AI agent owns `src/main/ai.ts`, optional provider/queue files and tests. Export `AIService(store,getKey,emit)`: `validateKey(key?)` returns `{valid,models:string[]}`; `models()`; `start()/stop()` background worker; `liveAppend(lectureId,pcm:Buffer)`; `liveCommit(lectureId,segment:Segment)`; `liveStop(lectureId)`; `flush(lectureId)` scheduling translation leftovers/final notes; `runAction({lectureId,versionId?,text?,action,language?,customActionId?})` returns Task; `improve(lectureId)` returns Task; `chatSend({conversationId,message})` returns ChatMessage; `cancel(taskId)`, `retry(taskId)`. Durable transcribe, translation, analysis and action tasks. UI controls live settings and main updates settings. Final original version creation handled by AI when all transcribe tasks finish (never overwrite once finalized). Live originals also assembled from segments. Work must persist first, API afterward. Chat retrieval scoped to selected IDs; complete coverage for summaries.

Root owns config, secure key, Electron main/preload, recording and renderer audio engine. Recording at 24kHz mono PCM via AudioWorklet, batches of ~250ms persisted to `.pcm.part` with fsync; 10s independent WAVs finalized atomically, stable seq and offsets. `record.start` `{lectureId,mode}` -> `{lectureId}`; `record.chunk` `{lectureId,pcm:ArrayBuffer,sequence:number}`; `record.pause/resume/stop` `{lectureId}`. Main alone holds secrets and sockets. `audio.url` `{lectureId,segmentId?}` -> URL and segment playlist metadata (renderer can simply use Segment paths through custom `lecture-audio://segment/id` URLs); `audio.sources` -> permissions/platform support. Mac target is 15+ with Electron 44 pinned to its documented ScreenCaptureKit path; Windows uses Electron's WASAPI loopback. No additional audio addon is required.

UI agent owns renderer except renderer/audio files. Root creates `src/renderer/audio/recorder.ts` exporting class `AudioCapture` with `devices():Promise<MediaDeviceInfo[]>`, `test(mode,deviceId,onLevel):Promise<()=>Promise<void>>`, `start(lectureId,mode,deviceId,onLevel,onError):Promise<void>`, `pause():Promise<void>`, `resume():Promise<void>`, `stop():Promise<void>`. Handles mixing/sampling/clipping/bounded buffering. UI calls record.start before capture start, capture.stop before record.stop, pause capture then record.pause, record.resume then capture.resume. Import picker args `{lectureId?,subjectId?}`; export `{lectureId,versionId?,format}` opens save dialog; folder.choose -> path|null; settings.save `{...settings patch}`; key.set `{key}`; key.validate `{key?}`; action.run args as AI above. Chat.create `{context,mode,title?}`, chat.send `{conversationId,message}`. Library event changed refreshes snapshot/detail. No demo data or fake successful operations. English/Russian/Ukrainian/Polish and themes. Stylish usable production app.
